# MOVIEBOX

Application React de gestion de films, avec ajout, modification, suppression, filtres et persistance locale. Chaque film possède une description et un lien intégré de bande-annonce ; sélectionnez une carte pour ouvrir ses détails.

## Développement

```bash
npm install
npm run dev
```

## Déploiement

Le projet est configuré pour GitHub Pages via GitHub Actions. Chaque push sur `main` déclenche automatiquement le build et le déploiement.

URL GitHub Pages : https://hamadoun-o-sidibe.github.io/hook-point/
