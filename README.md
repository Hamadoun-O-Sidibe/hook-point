# MOVIEBOX

Application React de gestion de films, avec ajout, modification, suppression, filtres et persistance locale.

## Développement

```bash
npm install
npm run dev
```

## Déploiement

Le projet est configuré pour GitHub Pages via GitHub Actions. Chaque push sur `main` déclenche automatiquement le build et le déploiement.

URL GitHub Pages : https://hamadoun-o-sidibe.github.io/hook-point/
